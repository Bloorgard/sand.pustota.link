# sand.pustota.link

Медитативный браузерный прототип для рисования конечной горстью песка с помощью регулируемого скребка.

**Live:** https://sand.pustota.link

## Возможности

- конечная масса песка на светлом столе;
- постоянно видимый скребок;
- регулируемые угол и длина скребка;
- перенос материала только при пересечении скребка с песком;
- неподвижная форма после завершения жеста;
- досыпание дополнительной порции возле скребка;
- мелкое чёрно-белое зерно;
- непрозрачный светлый стол;
- локальное сохранение состояния;
- экспорт результата в PNG;
- управление мышью, пером и касанием.

## Текущая модель

Песок хранится как конечное скалярное поле массы. Фоновое осыпание временно отключено. Движущаяся кромка забирает материал из полосы под скребком и переносит его по направлению жеста.

Клики и движения по пустому столу не изменяют поле. После завершения прохода форма сохраняется без дальнейшего дрейфа.

Рендер использует Canvas 2D. Зёрна отображаются как точки размером 1–2 пикселя на непрозрачном светлом фоне `#f4f4f1`.

Подробное описание находится в [`CONCEPT.md`](./CONCEPT.md).

## Локальный запуск

Проект не требует сборки или зависимостей:

```bash
python3 -m http.server 4173
```

Откройте http://localhost:4173.

## Лаборатория

`lab/index.html` — стенд для сравнения способов симуляции. Три движка на одном
скребке, переключаются на лету:

- **A · Карта высот** — непрерывное поле массы, зерно рисуется по плотности;
- **B · Зёрна** — частицы с координатами, скребок выталкивает их перед кромкой;
- **C · Гибрид** — масса в карте высот, зёрна срываются с кромки. Рабочая модель.

В гибриде песок слёживается после жеста, слой держит форму сцеплением, а лезвие
работает препятствием и не даёт валу осыпаться назад в расчищенный путь. Три
способа показать высоту: плотность, боковой свет, подъём с тенью.

Клавиши под левой рукой: `Q`/`W` — поворот скребка, `E`/`R` — шаг 45°,
`S`/`D` — длина, `A` — сыпать струёй под курсором.

Для воспроизводимых проверок страница держит отладочный мост `window.__lab`:
`stroke()` проводит жест, `pour()` сыплет, `settle()` прокручивает осыпание,
`probe()` и `widthAt()` меряют массу и ширину следа. Так гипотезы о физике
проверяются числами, а не на глаз.
