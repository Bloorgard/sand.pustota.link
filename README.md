# sand.pustota.link

Медитативный браузерный прототип для рисования конечной горстью песка с помощью регулируемого скребка.

**Live:** https://sand.pustota.link

## Возможности

- пустой стол, песок насыпается струёй туда, куда захочешь;
- стол вдвое больше окна: пробел двигает его, край обозначен пунктиром;
- постоянно видимый скребок, угол и длина меняются на лету;
- перенос материала только при пересечении скребка с песком;
- неподвижная форма после завершения жеста;
- мелкое зерно с боковым светом по умолчанию и плоским чёрно-белым вариантом;
- отмена жестов по `⌘Z`, двадцать шагов;
- сворачиваемые панели материала и клавиш;
- рисунок переживает изменение размера окна и переезд между экранами;
- локальное сохранение состояния;
- экспорт видимой области в PNG;
- управление мышью, пером и касанием.

## Клавиши

`Q`/`W` поворот · `⇧Q`/`⇧W` шаг 45° · `S`/`D` длина · `A` струя ·
`X` очистить · `⌘Z` отменить · `Space` двигать стол · `M` панель материала

## Текущая модель

Песок живёт в карте высот, по кромке скребка срываются отдельные зёрна.
Кромка непроницаема и сдвигает материал ровно настолько, насколько
продвинулась по своей нормали, поэтому движение вдоль лезвия приглаживает,
а поперёк — гребёт. Слой держит форму сцеплением, лезвие не даёт валу
осыпаться назад в расчищенный путь, а насыпь перед кромкой растёт вперёд и
ограничена высотой лезвия.

Масса сохраняется точно; это проверяется тестами, а не на глаз.

Модель целиком, вместе с причинами всех решений и масштабом единиц, описана
в [спецификации](./docs/superpowers/specs/2026-08-11-sand-simulation-design.md).
Продуктовая рамка — в [`CONCEPT.md`](./CONCEPT.md).

## Тесты

```bash
node --test tests/*.test.js
```

Девять проверок движка: сохранение массы, чистый путь на тонком слое, вал,
не обрушивающийся после жеста, высокое лезвие, несущее больше без грязного
следа, неподвижность песка при скольжении вдоль кромки, отказ грести слой
глубже лезвия, отсутствие пыли из крошек и переживание изменения размера
стола — вместе с переносом поля чужого размера.

## Лаборатория

`lab/index.html` — стенд для сравнения способов симуляции. Три движка на одном
скребке, переключаются на лету:

- **A · Карта высот** — непрерывное поле массы, зерно рисуется по плотности;
- **B · Зёрна** — частицы с координатами, скребок выталкивает их перед кромкой;
- **C · Гибрид** — масса в карте высот, зёрна срываются с кромки. Рабочая модель.

В гибриде песок слёживается после жеста, слой держит форму сцеплением, а лезвие
работает препятствием и не даёт валу осыпаться назад в расчищенный путь. Три
способа показать высоту: плотность, боковой свет, подъём с тенью.

Клавиши под левой рукой: `Q`/`W` — поворот скребка, `E`/`R` — шаг 45°,
`S`/`D` — длина, `A` — сыпать струёй под курсором.

Для воспроизводимых проверок страница держит отладочный мост `window.__lab`:
`stroke()` проводит жест, `pour()` сыплет, `settle()` прокручивает осыпание,
`probe()` и `widthAt()` меряют массу и ширину следа. Так гипотезы о физике
проверяются числами, а не на глаз.
